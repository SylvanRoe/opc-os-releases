# OPC OS Release 仓库

> 官方安装包发布仓库：仅含各版本安装包（tar.gz），不含源码。

## 当前版本
- **v0.8.4**（最新发布）：安装包 `opc-os-v0.8.4.tar.gz`。
- 请在右侧 **Releases** 面板下载，安装步骤见包内 `docs/installation-guide.md`（从零到可用完整手册）。

## 下载说明
- 请使用 GitHub **Release Asset** 下载（经 CDN，完整可靠）；**不可用** raw.githubusercontent.com 直链（会被截断，无法解压）。
- 下载后请比对 release 中的校验值（`md5sum opc-os-v0.8.4.tar.gz`）。
- 源码不在此仓库公开发布。
